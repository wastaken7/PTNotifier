Network

Address the WebUI listens on. Changes take effect after PTNotifier is restarted. If the saved address cannot be used at startup, PTNotifier falls back to 127.0.0.1:8085.

The address is set by --bind / PTN_BIND and cannot be changed here.
Reachable from other devices. Without HTTPS, your password and session cookie travel unencrypted on the network: only use this on a network you trust. To access PTNotifier over the internet, put it behind an HTTPS reverse proxy and start it with --trust-proxy instead of forwarding the port on your router. Windows may ask to allow PTNotifier through the firewall.
